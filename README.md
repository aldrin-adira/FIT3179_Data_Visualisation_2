# A nation of companions

An Australian pet-ownership data story by Aldrin Maqyl Bin Adira for FIT3179 Data Visualisation 2, Monash University Malaysia.

Six chapters explore international comparisons, ownership growth and housing, pet types and motivations, affordability, local conditions and lasting care. The website contains twelve Vega charts.

## Preview

Open this folder with VS Code Live Server or another local HTTP server. Open the served `index.html`, rather than opening it directly as a file, so charts can fetch their data.

No package installation or build step is required. Vega, Pure CSS and Google Fonts load from external services and require internet access.

## Website files

| Path | Purpose |
|---|---|
| `index.html` | Story, chart containers, sources and authorship. |
| `css/` | Layout, colours and typography. |
| `js/` | Vega chart specifications, chart loading and responsive layout. |
| `data/selected/` | Data and geographic boundaries loaded by the website. |
| [data/README.md](data/README.md) | Data inventory and explanation of generated display dots. |

Publish `index.html`, `css/`, `js/` and `data/selected/` to a static host such as GitHub Pages. Local development tools, validation tables and working documents are excluded from version control and are not needed to run the visualisation.

Full sources, methods, limitations and the artificial intelligence acknowledgement appear in the website footer.
